## What we're evaluating

Does the rotatable 3D scene explain how a local connection repeats in space? Can you find the green sphere **inside** the framework and use **Focus on pore** to inspect it without pretending we measured an actual pore size?

The real MOF-5 crystallographic rendering is a separate later step. The current 3D geometry remains deliberately schematic: its link spacing and sphere size are consistent **within the diagram**, not calibrated against a crystal structure. We will review actual crystallographic data separately.
