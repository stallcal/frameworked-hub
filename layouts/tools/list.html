A note about interpretation

Scherrer analysis estimates the extent of coherent scattering, not necessarily whole-particle dimensions. Instrumental broadening, lattice strain, profile choice, and overlapping peaks can change the result. This first release is intended for exploratory analysis and education, not validated metrology. Bruker BRML import is being evaluated, but is not yet supported.
