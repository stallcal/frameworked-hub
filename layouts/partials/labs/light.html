Beam opacity represents relative transmitted intensity, not the solution’s actual color. The blue calibration line uses the current path length; the red dot marks the selected concentration.

Change the sample.

A longer path gives the same solution more opportunity to absorb light.

The relationship

Absorbance grows linearly with concentration and path length. Transmission decreases exponentially with their product.

What changes

The model, explained.

{{ partial "equation.html" `A = \varepsilon\ell c = -\log_{10} T` }}{{ partial "equation.html" `T = \frac{I}{I_0} = 10^{-A}` }}

We hold the molar absorption coefficient ε at an illustrative 10,000 L mol⁻¹ cm⁻¹ at one fixed wavelength. ℓ is path length in cm, and c is concentration in mol/L. The slider uses µM, converted to mol/L before calculation. Absorbance has no units.

This assumes a homogeneous, dilute solution with unchanged chemical speciation and monochromatic light. Reflection, scattering, stray light, and detector limits are excluded, so light absorbed is 100% minus light transmitted. The graph is an ideal calibration, not experimental data.
