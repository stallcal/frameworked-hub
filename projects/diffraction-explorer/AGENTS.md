# Project instructions

Read README.md and MODEL.md first. Edit only web/ for the application and tests/ for model tests.
Keep scientific calculation functions in web/model.mjs free of DOM/browser dependencies.
Run `npm test` after changing the model. Serve web/ for browser checks; verify mobile layout,
invalid inputs, reset, download, keyboard operation, and assumptions. Do not infer scientific
validation from visual plausibility. Keep the model notes and version aligned with behavior.
Do not add remote data collection or network dependencies without an explicit requirement.
For integration in Frameworked, follow the root AGENTS.md and stage the generated tool copies.
