Why does phase control interference?

For two coherent waves with the same wavelength, frequency, and overlapping polarization, their displacements or field amplitudes add at each point. If A and B have equal amplitude, 0° relative phase produces a resultant twice as large; 180° makes the two contributions cancel at every position.

For arbitrary amplitudes A₁ and A₂, the resultant amplitude is R = √(A₁² + A₂² + 2A₁A₂ cos φ). At φ = 180°, R = |A₁ − A₂|, so cancellation is exact only when A₁ = A₂.

Relative phase can result from a path difference ΔL: φ = 360° × ΔL/λ (modulo 360°). Thus one wavelength of extra path brings a wave back into phase, while a half-wavelength produces an opposite phase.
